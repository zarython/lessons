# «دراستي» من الصفر — أكواد الدروس

برنامج مذاكرة ذكي بلغة بايثون نبنيه درساً بعد درس على قناة [Zarython](https://www.youtube.com/@zarython).
كل مجلد درس فيه `main.py` كما انتهى على الشاشة في ذلك الدرس، ومعه مجلد `assets` (خط Cairo والزخارف والأيقونة) الذي يحتاجه البرنامج.

| الدرس | المجلد | ما فيه |
|---|---|---|
| 1: شاشة المواد | [`lesson01/`](lesson01) | الألوان والخطوط، شريط العنوان، أدواتنا الصغيرة، وبطاقة لكل مادة |
| 2: نافذة إضافة مادة | [`lesson02/`](lesson02) | بطاقة «أضف مادة»، النموذج بأنواعه وموعد الامتحان والصعوبة، والقلم للتعديل |

## التشغيل

```bash
pip install -r dirasati/requirements.txt
python dirasati/lesson01/main.py
```

غيّر `lesson01` إلى مجلد الدرس الذي تريده. الملف `main.py` بجانب مجلد `assets`، فلا تفصل بينهما.

خط Cairo مرخّص برخصة SIL Open Font License، ونصّ الترخيص في `assets/fonts/FONTS.txt`.
