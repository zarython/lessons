متجري — نقطة نهاية الحلقة ٣
============================

ما أُضيف في هذه الحلقة:
  • حزمة Microsoft.Data.Sqlite (من NuGet)
  • Data\Database.cs            — أين يسكن ملفّ القاعدة، ونصّ الاتّصال، وإنشاء الجداول (التصنيفات والأصناف)
  • Models\Product.cs           — الصنف كما يراه البرنامج
  • Data\ReaderExtensions.cs    — قراءة عمود بالاسم، والفارغ لا يُسقط البرنامج
  • Data\ProductRepository.cs   — الاستعلام الثابت، وقراءة الصفّ، والبحث (بقيمة لها اسم، لا بلصق النصّ)
  • Forms\ProductsScreen.cs     — شاشة الأصناف: بحث فوق، وجدول، وثلاثة أزرار تحت
  • Core\UiTheme.cs             — لونان جديدان: Quiet و DeepRed
  • Forms\MainForm.cs           — زرّ الأصناف (F3) يفتح الشاشة الجديدة

جرّبها: F3 ← يظهر الجدول ← اكتب في البحث ← تتصفّى القائمة مع كلّ حرف.


كيف تشغّلها
-----------
١) افتح Matjari.slnx بـ Visual Studio 2026 Community.
٢) F5.

أو:  dotnet run --project Matjari


أين ملفّ القاعدة
----------------
   C:\ProgramData\Matjari\matjari.db

يُنشأ وحده أوّل تشغيل، بجداوله. افتحه ببرنامج DB Browser for SQLite (مجّانيّ) لترى الجدولين.


لماذا الجدول فارغ عندك
----------------------
الشاشة تقرأ من القاعدة، والقاعدة عندك جديدة لا صنف فيها. الأزرار الثلاثة (صنف جديد، تعديل، حذف)
مرسومة ولا تعمل بعد — هي موضوع الحلقة ٤. في الفيديو ظهرت أصناف تجريبيّة أدخلتُها في قاعدتي من قبل.

إن أردت أن ترى البحث يعمل الآن: افتح القاعدة بـ DB Browser وأدخل صفّين في جدول Products يدويّاً
(يكفي Code و Name و Unit و SalePrice و Quantity)، ثمّ شغّل البرنامج.


مهمّ إن انتقلتَ بين نقاط الحفظ
------------------------------
كلّ حلقة تضيف أعمدة وجداول. فإذا شغّلتَ نقطة حفظ أحدث فوق قاعدة أنشأتها نقطة أقدم، فقد تجد
أعمدة ناقصة — لأنّ CREATE TABLE IF NOT EXISTS لا يعدّل جدولاً موجوداً.

الحلّ الآن: احذف الملفّ   C:\ProgramData\Matjari\matjari.db   وشغّل من جديد.
